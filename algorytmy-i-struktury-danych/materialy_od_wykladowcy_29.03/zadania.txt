#
# Palindrom to słowo/zdanie, które czytane od tyłu brzmi tak samo
# jak od przodu (ignorujemy wielkość liter i spacje).
#
# Zasada działania:
#   1. Zamień napis na małe litery i usuń spacje
#   2. Włóż każdy znak oczyszczonego napisu na stos
#   3. Zdejmuj znaki ze stosu i porównuj z oryginałem znak po znaku
#   4. Jeśli wszystkie znaki się zgadzają — to palindrom
#
# WIZUALIZACJA
# ------------
#   Napis: "kajak"
#
#   Oczyszczony: "kajak"
#
#   Push: stos = [k, a, j, a, k]
#
#   Porównanie:
#     oryginał[0] = 'k'  vs  pop() = 'k'  → zgadza się ✅
#     oryginał[1] = 'a'  vs  pop() = 'a'  → zgadza się ✅
#     oryginał[2] = 'j'  vs  pop() = 'j'  → zgadza się ✅
#     oryginał[3] = 'a'  vs  pop() = 'a'  → zgadza się ✅
#     oryginał[4] = 'k'  vs  pop() = 'k'  → zgadza się ✅
#
#   Wynik: True — "kajak" jest palindromem ✅
#
# INPUT
# -----
#   napis: str — dowolny ciąg znaków
#
# OUTPUT
# ------
#   bool — True jeśli napis jest palindromem, False w przeciwnym razie
#
# PRZYKŁADY
# ---------
#   czy_palindrom("kajak")          → True
#   czy_palindrom("racecar")        → True
#   czy_palindrom("Ala ma kota")    → False
#   czy_palindrom("Kobyła ma mały bok") → True  (ignorujemy spacje i wielkość)
#   czy_palindrom("hello")          → False
#   czy_palindrom("")               → True  (pusty napis to palindrom)
#   czy_palindrom("a")              → True
#
# PODPOWIEDZI
# -----------
#   1. Użyj .lower() do zamiany na małe litery
#   2. Użyj .replace(" ", "") do usunięcia spacji
#   3. Wrzuć oczyszczony napis na stos (każdy znak osobno)
#   4. Zdejmuj ze stosu i porównuj z kolejnymi znakami oczyszczonego napisu
#   5. Jeśli jakakolwiek para się nie zgadza — zwróć False

TREŚĆ ZADANIA:
    Napisz funkcję wstaw_za(lista, szukana, nowe_dane), która znajduje
    PIERWSZY węzeł o wartości "szukana" i wstawia za nim nowy węzeł
    z danymi "nowe_dane".

    To naturalna operacja dla listy jednokierunkowej — w przeciwieństwie
    do tablic (list), nie operujemy na indeksach, lecz na wskaźnikach.
    Gdy MAMY węzeł, wstawienie za nim to O(1) — wystarczy przepiąć
    dwa wskaźniki, bez przesuwania jakichkolwiek elementów.

    Aby wstawić węzeł za danym węzłem, przepinamy wskaźniki:

    PRZED:   [szukana] -> [C] -> ...
    PO:      [szukana] -> [NOWY] -> [C] -> ...

    W liście jednokierunkowej nie da się wstawić PRZED danym węzłem
    w O(1), bo nie mamy wskaźnika "poprzedni" — musielibyśmy przejść
    listę od głowy. Dlatego wstawianie ZA węzłem jest operacją
    naturalną dla tej struktury.

INPUT:
    - lista: ListaJednokierunkowa — lista do modyfikacji
    - szukana: wartość węzła, za którym wstawiamy
    - nowe_dane: wartość nowego węzła

OUTPUT:
    - brak (funkcja modyfikuje listę w miejscu)
    - ValueError, jeśli szukana wartość nie istnieje w liście

PRZYKŁADY:
    Lista: 10 -> 30 -> 40 -> None
    wstaw_za(lista, 10, 20)  → 10 -> 20 -> 30 -> 40 -> None
    wstaw_za(lista, 40, 50)  → 10 -> 20 -> 30 -> 40 -> 50 -> None
    wstaw_za(lista, 99, 0)   → ValueError (99 nie istnieje)

    Lista z duplikatami: 5 -> 5 -> 10 -> None
    wstaw_za(lista, 5, 7)    → 5 -> 7 -> 5 -> 10 -> None
    (wstawia za PIERWSZYM znalezionym węzłem o wartości 5)

PODPOWIEDZI:
    1. Przejdź listę od głowy, szukając węzła z danymi == szukana.
    2. Gdy znajdziesz — utwórz nowy węzeł i przepnij wskaźniki:
       nowy.nastepny = znaleziony.nastepny
       znaleziony.nastepny = nowy
    3. Kolejność przepinania jest kluczowa! Najpierw podłącz nowy
       do reszty listy, potem dopiero podłącz znaleziony do nowego.
    4. Jeśli przejdziesz całą listę i nie znajdziesz → ValueError.

ZŁOŻONOŚĆ OBLICZENIOWA:
    Czasowa:  O(n) — w najgorszym przypadku szukana wartość jest
              na końcu listy i musimy przejść wszystkie węzły.
              Samo wstawienie (przepięcie wskaźników) to O(1).
    Pamięciowa: O(1) — tworzymy tylko jeden nowy węzeł.
